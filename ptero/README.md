# Pterodactyl Toolkit

Small scripts to help with installing and debugging Pterodactyl Wings.

- **install.sh**: Applies system optimizations, installs necessary dependencies (htop, curl, jq), and prompts you with the command to install Pterodactyl.
- **debug.sh**: Stops the wings service, dumps the latest error logs, checks for common known errors, and uploads the complete log online to easily share for support.
